Proyek dan tools

detection-engineering

Lihat README detection-engineering untuk penjelasan dan penggunaan.

privesc-audit

Scanner read-only yang meng-enumerate jalur privilege escalation Linux lewat 6 kategori check : SUID/SGID berisiko, sudo misconfig ( sudo -l ), capabilities berbahaya ( cap_setuid ), file/PATH/cron/systemd writable, ekspor NFS no_root_squash , dan keanggotaan grup pemberi-privesc (docker/lxd/disk/shadow) — di-cross-check ke GTFOBins . Punya mode baseline & diff (gerbang regresi hardening untuk CI), dengan laporan Markdown berisi evidence, remediasi, perubahan severity, dan mapping ATT&CK. v0.5.0 . Tiap temuan dapat remediasi + mapping MITRE ATT&CK . Full loop attack→detect→harden . Zero-dependency Python, teruji (pytest) + CI.

logsleuth

Engine deteksi untuk blue team: parse Linux auth log & web access log, lalu deteksi SSH brute-force, password spraying, login sukses pasca brute-force (breach), web scanning, dan SQLi/XSS — tiap temuan dipetakan ke MITRE ATT&CK . Output console/JSON/HTML, ranking severity, exit code untuk automation. Pure Python, teruji (pytest).

pcapsleuth

Analyzer lalu lintas jaringan untuk blue team: baca capture .pcap/.pcapng → rekonstruksi flow, ekstrak DNS/HTTP/TLS + IOC, dan deteksi perilaku mencurigakan — port scan, beaconing C2, DNS tunneling, kredensial cleartext, port backdoor, data egress — tiap temuan dipetakan ke MITRE ATT&CK . Output console/Markdown/HTML/JSON. v1.1.0 : filter --host IP_OR_CIDR untuk IPv4/IPv6, termasuk beberapa host/subnet; scope diterapkan sebelum statistik, IOC, dan deteksi. Pure Python (dpkt), 40 tes lulus.

maltriage

Triase report sandbox malware (CAPE/Cuckoo report.json ) menjadi satu verdict berskor: parse schema sandbox → ekstrak IOC (domain/IP/URL/dropped file/registry/mutex), petakan signature ke MITRE ATT&CK , ranking severity, dan rekonstruksi process tree. Output console/Markdown/HTML/JSON dan IOC CSV (v1.1.1) untuk spreadsheet/tiket, lengkap dengan nama, SHA256 dan tipe dropped file. Exit code untuk pipeline. 100% offline tanpa API key. Pure Python, 38 tes lulus + CI.

phishtriage

Alat triase email phishing (.eml) — tugas SOC L1 klasik. Menganalisis spoofing pengirim, hasil SPF/DKIM/DMARC , URL berbahaya (link IP, teks tak cocok dengan tujuan, punycode), lampiran berisiko, dan bahasa social-engineering → skor risiko berbobot + verdict. Output console/JSON/HTML. Pure Python, teruji (pytest).

ioc-hunter

Lihat README ioc-hunter untuk penjelasan dan penggunaan.

tokenpeek

Tool web (client-side) untuk analisis keamanan JWT: decode header/payload/signature, lalu deteksi kelemahan — alg=none , secret HMAC lemah (crack wordlist via Web Crypto di browser), header key-injection ( jku / jwk / kid ), data sensitif di payload, & expiry. Verifikasi signature RS/ES pakai public key. v1.1.0 : periksa issuer iss dan audience aud yang diharapkan, termasuk audience berbentuk daftar; hasil claim dipisahkan dari verifikasi signature. 100% di browser — token gak pernah keluar dari device. Zero dependency, 26 tes Node lulus.
